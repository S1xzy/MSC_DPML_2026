ตรวจข่าวปลอมให้เร็ว ด้วยการ “สร้าง” เส้นทางการแพร่ข่าวขึ้นมาเองDetect fake news early by generating its propagation path

RPPG-Fake ไม่รอให้ข่าวแพร่ไปจริงก่อน แต่ใช้เนื้อหาข่าวกับความรู้เรื่องพฤติกรรมผู้ใช้ทั้งแพลตฟอร์ม เพื่อจำลองว่า “ใครน่าจะแชร์ข่าวนี้ต่อ และเมื่อไร” แล้วใช้เส้นทางจำลองนั้นช่วยตัดสินว่าข่าวจริงหรือปลอม

RPPG-Fake does not wait for news to spread. It uses the news content and platform-wide user behaviour to simulate who is likely to share the item next, and when, then uses that simulated path to decide real or fake.

โมเดลแยกความน่าจะเป็นออกเป็น 3 ส่วน (Eq. 1) แต่ละส่วนคือหนึ่งโมดูล — คลิกเพื่อไปยังโมดูลนั้น

The model factorises the probability into three parts (Eq. 1), one per module — click a term to jump to it.

Content-based

ใช้แค่ข้อความ + รูป ตรวจได้ทันที แต่ข่าวที่ปั้นมาเนียน ๆ หลบได้ → แม่นต่ำ

Text + image only. Instant, but carefully fabricated news slips through → lower accuracy.

Propagation-enhanced

ใช้เส้นทางการแชร์จริง แม่นกว่า แต่ต้องรอให้ข่าวแพร่ไปแล้ว → ความเสียหายต่อสังคมสูง

Uses real sharing paths. More accurate, but only after the news has spread → high social hazard.

Module ① · Heterogeneous Graph Contrastive Learning

เรียนรู้ “ตัวตน” ของผู้ใช้จากกราฟทั้งแพลตฟอร์มLearn who each user is from the platform-wide graph

คืออะไร: สร้างกราฟ heterogeneous H = (V, E, U) ที่มีโหนด 3 ชนิด คือ Publisher, News และ User แล้วเรียน user embedding แบบ self-supervised (ไม่ใช้ label) ทำไม: โมดูล ② ต้องเลือกว่า “ใครจะแชร์ต่อ” — ถ้า embedding ของผู้ใช้ไม่ดี การเลือกก็จะมั่ว

What: build a heterogeneous graph H = (V, E, U) with three node types — Publisher, News, User — and learn user embeddings self-supervised (no labels). Why: Module ② must decide who shares next; poor user embeddings make that choice random.

เรียนผ่าน 2 มุมมอง: Node view จับโครงสร้างการแพร่ระดับ global และ Meta-path view จับความสัมพันธ์เชิงความหมายข้ามชนิดโหนด แล้วรวม loss: L_CL = Σ [λ₁·L_node + (1−λ₁)·L_meta]

Two views: the node view captures global propagation topology, the meta-path view captures semantic relations across node types. Losses combine as L_CL = Σ [λ₁·L_node + (1−λ₁)·L_meta].

Module ② · Reinforced Propagation Paths Generation

ให้ agent เลือกทีละขั้นว่า “ใครจะแชร์ข่าวต่อ”An agent decides, step by step, who shares the news next

คืออะไร: มองการแพร่ข่าวเป็น Markov Decision Process (MDP) เพราะผู้ใช้เป็นค่า discrete จึงหาอนุพันธ์ตรง ๆ ไม่ได้ จึงใช้ reinforcement learning (policy gradient) เริ่มจาก: โหนดของข่าวเอง จึงสร้าง path ได้แม้ยังไม่มีใครแชร์จริงเลย

What: treat news spreading as a Markov Decision Process (MDP). Users are discrete, so the generator is not differentiable — hence reinforcement learning (policy gradient). Start: the news node itself, so a path can be generated even before anyone has shared it.

Policy network (Eq. 7–11)

uᵢ = Tanh(W_u [ûᵢ ; Σₗ ĥᵢ^Φl])
sₜ = [μₜ ; vₜ ; n]

μₜ = ภาพรวม subgraph ที่สร้างแล้ว · vₜ = ค่าเฉลี่ยผู้ใช้ที่เพิ่งเข้ามา · n = เนื้อหาข่าว → เลือกผู้ใช้โดย “รู้บริบทข่าว” · รับ K₂ edges ต่อ action และมี self-loop · หยุดเมื่อ |Vₜ| = T

μₜ summarises the subgraph so far · vₜ averages new users · n is the content → news-aware choices · K₂ edges per action plus a self-loop · stop at |Vₜ| = T.

Rewards (Eq. 12–14)

R_T (temporal): แบ่งเวลา path จริงเป็นช่วง เก็บผู้ใช้ที่ active ในช่วง t เป็น Ω(t) ให้รางวัลเมื่อผู้ใช้ที่เลือกคล้ายค่าเฉลี่ยของ Ω(t)

R_T (temporal): split the real path into time slots, Ω(t) = users active in slot t; reward users similar to the mean of Ω(t).

R_G (global): discriminator D แยก path จริงกับ path ที่สร้าง (แนวคิด GAN) ให้โครงสร้างรวมเหมือนจริง

R_G (global): a discriminator D separates real from generated paths (GAN idea) so the overall structure looks real.

R(uᵢ,t) = cos(uᵢ, mean Ω(t))
R_G = −(E_real[log D] + E_π[log(1−D)])
R_C = λ₂·R_T + (1−λ₂)·R_G

Actor–Critic (Eq. 15–19)

qₜ = R_C + γ·E[Q_φ(sₜ₊₁,a)]
L_critic = (Q_φ(sₜ,aₜ) − qₜ)²
∇_θJ ≈ Q_φ(sₜ,aₜ)·∇_θ log π_θ(sₜ,aₜ)

Module ③ · Temporal-aware Fake News Detection

อ่าน path ที่สร้างขึ้นตามลำดับเวลา แล้วตัดสินจริงหรือปลอมRead the generated path over time, then decide real or fake

คืออะไร: นำ G′ จากโมดูล ② มาเข้ารหัส 2 มุม คือ temporal feature (path เปลี่ยนไปอย่างไรในแต่ละช่วงเวลา) และ structure feature (รูปร่างของ path ทั้งก้อน) แล้วรวมกับเนื้อหาข่าว (ข้อความ + รูปภาพ) เพื่อทำนาย

What: encode G′ from Module ② from two angles — temporal features (how the path grows over time) and structure features (the shape of the whole path) — then combine with the news content (text + image) to predict.
