Paper Roadmap

From the problem to the results and how the model is evaluated. Click a box for details.

Background & Motivation

Propagation paths help detect fake news — but waiting for them means the damage is already done.

Problem

Fake news is well-fabricated

  • Text + image look credible
  • Content-only models miss it
Useful signal

How news spreads

  • Fake news paths are wider and deeper
  • More bots / automated accounts
Dilemma

Efficacy vs. social hazard

  • Rich paths exist only after wide spread
  • Extra context (profiles, comments) is costly
Idea

Generate the future path

  • Simulate who would share the news
  • From content only, at time ≈ 0

The dilemma, interactively

Toy spread · numbers = PolitiFact accuracy from Tables II–III
Social hazard (users already reached)

Contributions

  • First to do early fake news detection by generating propagation paths
  • RPPG-Fake: RL-based path generation + temporal-aware detection
  • Beats state-of-the-art baselines on 3 real-world datasets

Training setup (paper)

AdamWlr 5e-3batch 16user embedding 128-dsplit 7:1:25 runs, mean reportedPyTorch 1.13 · RTX 3090

Key hyper-parameters: τ₁, τ₂ (contrastive temperatures), λ₁ (node vs meta-path loss), λ₂ (temporal vs global reward), K₁ (pos/neg samples), K₂ (users added per action), T (max users). Final values are not stated; only sensitivity plots (Fig. 4).

Data

Multimodal news + social context. Each news item = text + image + who shared it, from whom, and when.

Text

News article (PolitiFact, GossipCop) or tweet (Pheme)

Image

Image attached to the news (code: text feature is reused if missing)

Propagation

Engagements (head_user → user, timestamp) = retweet / repost cascade

Social graph H

Nodes: publisher · news · user. Meta-paths PNU, NUN, UNU

  • Baseline list: LLAMA2 and Detect-GPT are described with CAFE's sentence and citation [4]

      Summary

      News text + image+ RL-generated propagation path→ Temporal + structure GNN→ Fake / Real, early

      What it does

      Detects fake news before it spreads by simulating who would share it, then using that simulated path as social context.

      How

      Contrastive GNN on a publisher–news–user graph → actor-critic agent generates paths → dynamic GAT + attention fusion → classifier.

      Data

      PolitiFact, GossipCop, Pheme · text + image + engagements · random 7:1:2 split · early stage = 3–5 engagements.

      Results

      Early-stage Acc 0.902 / 0.873 / 0.829 (+4.0 / +4.1 / +2.7 pp). Best on PolitiFact & Pheme with full paths too.

      Strengths

      • Clear, important problem framing
      • Uses social context without waiting for it
      • Ablation + sensitivity + case study

      Watch out for

      • Code does not run; key parts missing
      • Code ≠ paper (rewards, encoder, split)
      • Small test sets, no std
      • Several inconsistent numbers
