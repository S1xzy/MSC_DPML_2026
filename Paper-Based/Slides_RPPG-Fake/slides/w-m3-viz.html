Detector อ่านกราฟทีละ snapshot แล้วใช้ attention

ค่า attention จริงจาก detector PHEME รอบ 8 seed 2 (เฉลี่ย 4 head) · ข่าว test “Love is Stronger than Hate…” · Slides_RPPG-Fake/figures/export_m3.py

ภาพนี้ได้จากการรัน detector ที่ train แล้วกับข่าวเดียวกับสองสไลด์ก่อนหน้า แถวบนคือ snapshot ของกราฟการแพร่ที่ detector เห็น เริ่มจาก 2 node คือตัวข่าวกับคนแชร์คนแรก จนถึง 201 node เมื่อรวม user ที่ generate ทั้งหมด detector ใช้ GAT อ่านแต่ละ snapshot ได้เวกเตอร์หนึ่งตัวต่อ snapshot แถวล่างซ้ายคือ self-attention ระหว่าง snapshot ทั้ง 23 ตัว ทุกแถวไปรวมที่ snapshot 4 และ 6 เกือบทั้งหมด แถวล่างขวาคือ cross-attention ที่ลำดับ snapshot มองไปยัง node ของกราฟสุดท้าย น้ำหนักไปอยู่ที่ user ที่ generate ทั้งหมด และ 90% อยู่ที่แค่ 3 คน ส่วนคนแชร์จริง 3 คนแรกได้น้ำหนักเกือบศูนย์ สรุปคือ attention ของ model ไปกระจุกที่ไม่กี่จุด ไม่ได้ใช้ข้อมูลจากทั้งเส้นทาง ซึ่งสไลด์ถัดไปจะแสดงผลที่ตามมา
