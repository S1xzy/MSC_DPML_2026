Module 2 มองการสร้างเส้นทางเป็น MDP: state คือเส้นทางที่สร้างไว้แล้ว + user ที่เพิ่งเพิ่ม + embedding ของข่าว action คือเลือก user K2 คนจาก candidate (repost, co-engagement, content similarity) reward มีสองส่วน temporal reward = ความคล้ายระหว่าง user ที่เลือกกับกลุ่มคนที่แชร์จริงใน time step นั้น (Λ(t)) และ global reward = −log(1 − D(G′)) จาก discriminator ที่แยกเส้นทางจริงกับเส้นทางที่สร้าง train ด้วย actor-critic แล้วสร้าง G′ ให้ทุกข่าวรวมถึงข่าว test
