Module 1 เรียน embedding ของ user จากกราฟสังคมด้วย contrastive learning ซึ่งไม่ใช้ label Module 2 ใช้ embedding นั้นเป็น state และ action ของ RL agent เพื่อสร้างเส้นทาง G′ ให้ทุกข่าว ทั้งสอง module train ใน Stage 1 จากนั้น Stage 2 train Module 3 ด้วย label ของข่าว โดยรับเส้นทางจริงช่วงแรก + G′ + เนื้อหาข่าว
