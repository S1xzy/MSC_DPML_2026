หลังแก้ bug ผลของ GossipCop ขึ้นมาก เราจึงตรวจ data leakage สี่ข้อโครงสร้างผ่านทั้งหมด ยกเว้นมีข่าวซ้ำระหว่าง train และ test บางส่วน ซึ่งเป็นลักษณะของ dataset ทดสอบชี้ขาดคือสลับ label ของ train แบบสุ่มแล้ว train detector ใหม่ ถ้า model โกงด้วยข้อมูลที่รั่ว ผลจะยังสูง แต่ผลที่ได้ตกเหลือระดับเดาคลาสส่วนใหญ่ทุก dataset ผลดีจึงมาจากสัญญาณจริงใน dataset: user ที่แชร์ข่าว fake มักแชร์ fake ซ้ำหลายข่าว กฎง่าย ๆ ที่ดู label ของข่าวที่ user ช่วงแรกเคยแชร์ ได้ถูก 92% บน GossipCop AUC ของ model ที่ train ด้วย label สุ่มห่างจาก 0.5 ได้ทั้งสองทาง เพราะ input มีข้อมูล label อยู่แล้ว ทิศคะแนนจึงสุ่ม แต่ accuracy ไม่เคยสูงกว่าการเดา
