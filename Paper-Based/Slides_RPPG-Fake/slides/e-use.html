ติดป้ายเตือน · ชะลอการกระจาย

ใครใช้ได้

• แพลตฟอร์มโซเชียล: จัดคิวให้ทีมตรวจสอบ

• สำนัก fact-check: เลือกข่าวที่ต้องตรวจก่อน

• หน่วยงาน: เฝ้าระวังข่าวลือช่วงวิกฤต

ข้อควรระวัง (จาก demo ของเรา)

• ต้อง retrain เมื่อมีเหตุการณ์ / user ใหม่

• ใช้จัดลำดับ (AUC) ดีกว่าตัดสินด้วย 0.5

• ช่วยคนตัดสิน ไม่ใช่ตัดสินแทน

input ที่ต้องมี: ข้อความ + รูป + ใครแชร์ต่อจากใคร เมื่อไร (เช่นจาก API ของแพลตฟอร์ม)

ในชีวิตจริง model นี้เหมาะเป็นระบบเตือนล่วงหน้า: พอข่าวใหม่มีคนแชร์ 3–5 ครั้ง ระบบเก็บข้อความ รูป และข้อมูลการแชร์ ส่งเข้า model ได้คะแนนความน่าจะเป็นว่าปลอม ข่าวคะแนนสูงจะถูกส่งให้ fact-checker ตรวจก่อน หรือติดป้ายเตือน จาก demo B เรารู้ว่าถ้าเจอเหตุการณ์ใหม่และ user ใหม่ model จะพลาดมาก จึงต้อง retrain เป็นระยะ ใช้คะแนนเพื่อจัดลำดับดีกว่าใช้ threshold ตายตัว และควรให้คนเป็นผู้ตัดสินสุดท้าย
