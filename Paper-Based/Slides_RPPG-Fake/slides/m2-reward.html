Reward มีสองส่วน Temporal reward (Eq. 12): แบ่งเวลาการแพร่ของเส้นทางจริงเป็นช่วงเท่า ๆ กัน Λ(t) คือรายชื่อคนที่แชร์จริงในช่วง t ให้คะแนนตามความคล้าย (cosine) ระหว่าง user ที่ agent เลือกกับค่าเฉลี่ยของคนใน Λ(t) เพื่อให้เลือกคนที่น่าจะแชร์ในช่วงเวลานั้น Global reward (Eq. 13): discriminator D ถูก train ให้แยกเส้นทางจริงกับเส้นทางที่สร้าง ส่วน generator ได้คะแนนเมื่อหลอก D ได้ แบบเดียวกับ GAN reward รวม R_C = λ2·R_T + (1−λ2)·R_G (Eq. 14) การเรียนใช้ actor-critic: critic Q(s,a) (Eq. 15) train ด้วย temporal difference ให้ Q ใกล้ q_t = R_C + γ·E[Q(s_t+1, a)] (Eq. 16–17) ส่วน actor (policy) ปรับด้วย policy gradient ∇J ≈ Q(s,a)·∇log π(s,a) (Eq. 18–19)
