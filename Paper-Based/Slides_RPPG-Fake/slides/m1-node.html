Node-view contrastive learning มีเป้าหมายให้ embedding ของ user สะท้อนโครงสร้างการแพร่ทั้งระบบ ขั้นแรกรบกวน feature ของ node ด้วย PGD (ũ = u + δ) เพื่อสร้างตัวอย่างที่ยากขึ้น จากนั้นสำหรับแต่ละ node หา K1 node ที่คล้ายที่สุด (cosine) เป็นเซตบวก V^p และ K1 node ที่ต่างที่สุดเป็นเซตลบ V^n แล้วใช้ Graph Attention Network รวมข้อมูลจากเพื่อนบ้าน โดยให้น้ำหนักแต่ละเพื่อนบ้านตาม attention (Eq. 2) ได้ embedding û สุดท้ายใช้ contrastive loss แบบ InfoNCE (Eq. 3) ดึง embedding เข้าใกล้คู่บวกและผลักออกจากคู่ลบ ทั้งหมดไม่ใช้ label ของข่าว
