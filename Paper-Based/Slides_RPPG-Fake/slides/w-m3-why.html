สิ่งที่เราทำ

PHEME: ข้อความ + ภาพตัดสินผล เส้นทางแทบไม่มีผล

PHEME

0 / 6 run ใช้เส้นทาง

GossipCop

5 / 6 run ใช้เส้นทาง

PolitiFact

1 / 6 run ใช้เส้นทาง

“ใช้เส้นทาง” = ถ้าแทนส่วนเส้นทางด้วยค่าเฉลี่ย test acc ลด ≥ 5 pp · 3 seeds × early / full · ตรวจหลังเลือก model แล้ว ไม่ได้ใช้ปรับ model

ชั้นสุดท้ายของ detector เป็นสมการเส้นตรง P(real) = σ(W·[h*; n_T; n_V] + b) จึงแยก logit ออกเป็นส่วนที่มาจากเส้นทาง (h*), ข้อความ, ภาพ และค่าคงที่ได้พอดี ซ้าย: ข่าว real และข่าว fake ได้ส่วนของเส้นทางเท่ากันที่ +0.92 สิ่งที่ทำให้สองข่าวต่างกันคือข้อความและภาพจาก CLIP ขวา: ลองให้ detector ตัวเดิมเห็น G′ แค่ 0 ถึง 20 step P(real) แทบไม่เปลี่ยน เมื่อตรวจทุก run พบว่า PHEME ทั้ง 6 run ส่วนของเส้นทางแทบเป็นค่าคงที่ (h* ยุบ) ผลของ PHEME ที่ตรงกับ paper จึงมาจากเนื้อหาข่าวเกือบทั้งหมด GossipCop ใช้เส้นทางจริง ถ้าตัดออก accuracy ลด 6–26 pp ใน 5 จาก 6 run และ run ที่ไม่ใช้เส้นทางคือ seed 1 ซึ่งได้ผลต่ำสุด (0.777) PolitiFact ใช้แค่ 1 จาก 6 run นี่อธิบายเพิ่มว่าทำไม G′ ไม่ช่วยใน PHEME และ PolitiFact การวิเคราะห์นี้ทำหลังเลือก model ด้วย validation แล้ว ไม่ได้ใช้ปรับ model
