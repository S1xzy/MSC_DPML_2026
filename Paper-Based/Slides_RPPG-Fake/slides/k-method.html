06 · การวิพากษ์การวิจัย · วิธีการและการประเมินผล

วิพากษ์ Paper

การทดลองยังไม่พอจะยืนยันข้ออ้างหลัก

1 · ไม่มีการเทียบกับ “ไม่ใช้ G′”

Table IV เทียบแค่ RL vs Random / Similarity

ของเรา: ไม่ใช้ G′ ได้เท่ากันหรือดีกว่าทุก dataset

2 · ต้องรู้จัก user ล่วงหน้า

user เป็น node ในกราฟ H · ไม่ทดสอบข้ามเหตุการณ์

ของเรา: เหตุการณ์ใหม่ Acc 0.25 (รู้จัก user แค่ 15%)

3 · Benchmark ให้รางวัลการจำ user

ไม่ได้แยกว่าผลมาจากเนื้อหา หรือจากประวัติ user

ของเรา: ดูแค่ประวัติ user ทายถูก 92% (GossipCop) / 69% (PHEME)

4 · ส่วนต่างเล็กกว่าความแกว่ง

ablation ต่างกัน 1–2 pp · ไม่มี significance test

ของเรา: std ระหว่าง seed ±1–9 pp

ข้อ 2 ตรงกับงานในอนาคตที่ผู้เขียนเขียนเอง: “ปรับตัวข้ามโดเมน”

ตัวเลขสีส้ม = จากการทดลองของเรา (รอบ 8, 3 seeds)

ด้านวิธีการและการประเมินผล ข้ออ้างหลักของ paper คือเส้นทางที่สร้างด้วย RL (G′) ช่วยตรวจจับช่วงแรก แต่ ablation ใน Table IV เทียบแค่วิธีสร้าง G′ แบบต่าง ๆ ไม่มีแถวที่ไม่ใช้ G′ เลย ซึ่งในการทดลองของเราการไม่ใช้ G′ ได้ผลเท่ากันหรือดีกว่า ข้อสอง model ใช้ user เป็น node ในกราฟ จึงต้องรู้จัก user ล่วงหน้า และ paper ไม่ได้ทดสอบกับเหตุการณ์หรือ user ใหม่ ข้อสาม ในชุดข้อมูลเหล่านี้แค่ดูประวัติของ user ที่แชร์ก็ทายได้สูงมาก paper ไม่ได้แยกว่าความแม่นมาจากเนื้อหาหรือจากการจำ user ข้อสี่ ส่วนต่างใน ablation อยู่ที่ 1–2 pp ซึ่งเล็กกว่าความแกว่งระหว่าง seed ที่เราวัดได้ ควรมีการทดสอบนัยสำคัญ ข้อสองนี้ผู้เขียนเองก็ระบุไว้เป็นงานในอนาคต
