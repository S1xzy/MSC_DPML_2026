06 · การวิพากษ์การวิจัย · ความสามารถในการทำซ้ำ

วิพากษ์ Paper

Paper ทำซ้ำตามที่เผยแพร่ไม่ได้

Code ใช้ไม่ได้

• ไฟล์ config และ source บางส่วนหาย

• ตัวแปรหลายตัวไม่ได้ประกาศ

• val / test สลับกัน

• ไม่มี reward และ discriminator ตาม Eq. 12–14

ค่าพารามิเตอร์ไม่ครบ

• τ1, τ2, λ1, λ2, K1, K2, T มีแค่กราฟ Fig. 4 ไม่มีตัวเลข

• ไม่ระบุ RL epoch, dropout, GAT heads, PGD ε, γ

• ไม่เปิด encoder ข้อความ / ภาพที่ใช้

ข้อมูลไม่ครบ

• repo มีแค่ PolitiFact 483 ข่าว

• ไม่มีภาพ ทั้งที่เป็น model multimodal

• ไม่มี publisher (ทุก cascade เริ่มจาก user เดียวกัน) → สร้าง PNU ไม่ได้

• ไม่ให้ GossipCop / PHEME

ผลที่ตามมา

ต้องเขียนใหม่ทั้ง 3 module · ตีความเองอีก 10 จุดที่ paper ไม่ชัด (เช่น Λ(t), state เริ่มต้น, ชุด action, การ train D) · สร้าง dataset 2 ชุดเอง

Code ทางการ github.com/LitianD/RPPG-Fake · รายการทั้งหมด: Code_RPPG-Fake/RUNNING.md ข้อ 5

ด้านความสามารถในการทำซ้ำ paper มีปัญหาสามด้าน หนึ่ง code ทางการรันไม่ได้: ไฟล์ config และ source บางส่วนหาย ตัวแปรไม่ได้ประกาศ ใช้ val กับ test สลับกัน และไม่มีส่วน reward กับ discriminator ตามสมการ สอง ค่าพารามิเตอร์สำคัญของ RL และ contrastive learning มีแค่กราฟ sensitivity ใน Fig. 4 ไม่มีค่าที่ใช้จริง และไม่บอกจำนวน epoch, dropout หรือ encoder ที่ใช้ สาม ข้อมูลใน repo มีแค่ PolitiFact ที่ไม่มีภาพและไม่มี publisher ทำให้สร้าง meta-path PNU ไม่ได้ และไม่มี GossipCop หรือ PHEME ให้ เราจึงต้องเขียนใหม่ทั้งหมด ตีความเองสิบจุด และสร้าง dataset ใหม่เอง ซึ่งทุกข้อทำให้ผลของเราต่างจาก paper ได้
