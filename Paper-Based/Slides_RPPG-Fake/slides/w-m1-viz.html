ภาพนี้คือ embedding จริงของ user ใน PHEME ที่ Module 1 เรียนรู้ ลดจาก 128 มิติเหลือ 2 มิติ แต่ละจุดคือ user หนึ่งคน สีบอกว่า user คนนั้นเคยแชร์ข่าว fake มากแค่ไหนในชุด train สีน้ำเงินแชร์แต่ข่าวจริง สีส้มแชร์แต่ข่าวปลอม ซ้ายคือก่อนแก้ bug ในรอบ 6 ทุกคนได้เวกเตอร์เดียวกัน จึงซ้อนกันเป็นจุดเดียว model จึงแยก user ไม่ออกเลย ขวาคือหลังแก้ bug ในรอบ 8 user แยกเป็นกลุ่ม และมีกลุ่มที่สีส้มหนาแน่น แปลว่า embedding เก็บข้อมูลว่าใครมักแชร์ข่าวแบบไหนไว้ได้ แม้ model ไม่ได้เห็น label ตอนเรียน embedding ดาวสีดำคือ u258 จากสไลด์ก่อนหน้า เพื่อนบ้านใกล้สุด 5 คนอยู่ติดกันจนซ้อนเป็นจุดเดียว ข้อควรระวัง: t-SNE รักษาความใกล้เฉพาะจุด ระยะระหว่างกลุ่มใหญ่ไม่มีความหมายโดยตรง
