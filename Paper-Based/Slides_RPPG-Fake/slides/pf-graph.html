นี่คือกราฟย่อยจริงจาก H ของ PHEME (seed 2) รอบข่าว A “Love is stronger than hate: #CharlieHebdo cover after Molotov cocktail attack” มี user 5 คนแชร์ข่าวนี้ (เส้นเทา) ในนั้นมีการ repost ต่อกันสองคู่: u2817 → u2818 และ u2819 → u2820 (เส้นประส้ม) และ u2819 เคยแชร์ข่าว B, C ส่วน u174 เคยแชร์ข่าว D, E ทำให้ข่าวหลายชิ้นเชื่อมกันผ่าน user (meta-path NUN) และ user เชื่อมกันผ่านข่าว (UNU) ในเครื่อง H เก็บเป็นรายการ edge: edge_index ขนาด 2 × 53,526 (นับทั้งสองทิศ) edge_type บอกชนิด (0 = repost, 1 = แชร์ข่าว) และ edge_origin บอกว่า edge มาจากข่าว train ชิ้นไหน เพื่อให้ตอน train RL ซ่อนเส้นทางของข่าวตัวเองได้ node id ของ user คือ 0–49,325 และข่าว i คือ 49,326 + i H สร้างจากข่าว train 1,402 ชิ้นเท่านั้น มี user ที่มี edge 14,583 คน ใน paper กราฟมี node publisher ด้วย แต่ข้อมูลที่มีไม่มีผู้เผยแพร่ จึงใช้ความสัมพันธ์ user–user (UU) แทน meta-path PNU
