P → N → U

PNU

ผู้เผยแพร่ → ข่าว → คนที่แชร์

N → U → N

NUN

ข่าวสองชิ้นที่คนกลุ่มเดียวกันแชร์

U → N → U

UNU

user สองคนที่แชร์ข่าวเดียวกัน

1 · RWR ตาม meta-path

สุ่มเดินแบบเริ่มใหม่ได้ → เพื่อนบ้านที่เจอบ่อย = กราฟ H^l

2 · GAT ต่อ meta-path

ได้ embedding h^l ของ node ในแต่ละมุมมอง

3 · Contrastive (Eq. 4)

node เดียวกันต่างมุมมอง = คู่บวก · ต่าง node = คู่ลบ (τ₂)

รวมสองมุมมอง (Eq. 5)

L_CL = λ₁·L_node + (1 − λ₁)·L_meta

user embedding ที่ส่งต่อ (Eq. 7)

u = tanh(W·[û ; Σ_l h^l])

Section III-A2 · Eq. 4–5, 7 · τ₂ = 0.3, λ₁ = 0.4 · ข้อมูลของเราไม่มี publisher → ใช้ UU แทน PNU

Node view จับโครงสร้างได้ แต่ไม่แยกชนิดความสัมพันธ์ meta-path view จึงมองกราฟผ่าน “เส้นทางความหมาย” เช่น PNU (ผู้เผยแพร่ → ข่าว → ผู้ใช้), NUN (ข่าวที่มีคนกลุ่มเดียวกันแชร์) และ UNU (ผู้ใช้ที่แชร์ข่าวเดียวกัน) สำหรับแต่ละ meta-path ใช้ random walk with restart เลือกเพื่อนบ้านที่เจอบ่อยเป็นกราฟความหมาย H^l แล้วใช้ GAT แยกต่อ meta-path ได้ h^l จากนั้น contrastive loss (Eq. 4) ให้ node เดียวกันในสองมุมมองมี embedding ใกล้กัน และต่าง node ไกลกัน loss รวมคือ λ1·L_node + (1−λ1)·L_meta (Eq. 5) embedding ที่ส่งให้ Module 2 คือ tanh ของการรวม û กับผลรวม h^l (Eq. 7)
