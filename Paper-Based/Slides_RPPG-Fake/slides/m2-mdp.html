Module 2 มองการสร้างเส้นทางเป็น Markov Decision Process ที่มี state, action, reward และ transition State ที่ step t คือ (ข่าว, user ใหม่ U_t, user ทั้งหมด V_t, เส้น R_t) แปลงเป็นเวกเตอร์ [Π_t ; v_t ; n] โดย Π_t คือการรวม user ในกราฟย่อยด้วย attention (Eq. 9), v_t คือค่าเฉลี่ยของ user ที่เพิ่งถูกเพิ่ม (Eq. 10) และ n คือเนื้อหาข่าว Action คือการเลือกความสัมพันธ์ขาออก (r, e) จาก user ที่อยู่ในเส้นทางไปหา user ใหม่ในกราฟ H เพื่อความเร็วจะรับ K2 action ต่อ step และมี self-loop ที่หมายถึงไม่มีใครแชร์เพิ่ม Policy (Eq. 11) ให้คะแนนแต่ละ action ด้วย MLP แล้ว softmax Transition เป็นแบบแน่นอน (Eq. 6) คือเพิ่ม user และเส้นเข้าไป ทำซ้ำจนเส้นทางมีครบ T users
